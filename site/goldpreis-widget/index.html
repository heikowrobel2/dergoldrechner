Goldpreis-Widget für Ihre Website

Zeigen Sie den aktuellen Gold- und Silberpreis auf Ihrer Website – kostenlos, ohne Anmeldung, ohne Cookies und ohne Tracking.

So sieht das Widget aus

Code zum Einbinden

Kopieren Sie diesen Code an die Stelle Ihrer Website, an der der Goldpreis erscheinen soll:

<iframe src="https://dergoldrechner.de/widget/" title="Goldpreis heute" width="300" height="190" style="border:0;max-width:100%" loading="lazy"></iframe>
<p style="font-size:12px">Goldpreis von <a href="https://dergoldrechner.de/">dergoldrechner.de</a></p>

Das Widget lädt den Kurs direkt von unserem Server und aktualisiert sich bei jedem Seitenaufruf. Es setzt keine Cookies und verwendet kein Tracking. Wie bei jedem eingebetteten Inhalt wird beim Laden die IP-Adresse des Besuchers an unseren Server übermittelt; sie wird nur für den technischen Betrieb in den Server-Logs verarbeitet. Breite und Höhe können Sie anpassen; der Hinweis mit dem Link unter dem Widget sollte erhalten bleiben.

Häufige Fragen

Kostet das Goldpreis-Widget etwas?

Nein. Das Widget ist kostenlos und ohne Anmeldung nutzbar.

Woher stammt der Goldpreis im Widget?

Es ist derselbe Kurs wie auf dergoldrechner.de: der internationale Spotpreis in Euro, stündlich aktualisiert und mit einer zweiten Quelle abgeglichen.

Setzt das Widget Cookies?

Nein. Es lädt nur den aktuellen Kurs und setzt weder Cookies noch Tracking. Technisch bedingt wird beim Laden die IP-Adresse an unseren Server übermittelt.
